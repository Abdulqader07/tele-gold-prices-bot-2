# Gold Price Alert Bot

**Live Telegram bot with 9 active users monitoring gold prices**

## Why I Built This

I personally own gold and wanted real-time price alerts. Instead of checking manually, I built a bot that does it for me and 8 other people.

## What It Does

- Fetches live gold prices every 25 minutes
- Sends Telegram alerts when price changes significantly
- Supports 24k, 22k, 21k, 18k gold prices per gram
- Admin controls for broadcasting and user management

## Live Status

- **Active Users:** 9
- **Uptime:** 99.9% (running for X days)
- **Price checks:** ~57 per day
